The funniest excuse a robot vacuum gives for missing a spot, in one line: it didn't skip the corner — its cliff sensor saw the rug fringe, panicked, and filed it as a staircase to nowhere.

## Run it

```sh
python3 main.py
```

The program writes the single line to `/output/entry.txt`.
